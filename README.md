# 🌐 Language Translation Tool

A simple and responsive web-based Language Translation Tool developed for the Code Alpha Internship Task 1.

## 📌 Features

- Enter text for translation
- Select source language
- Select target language
- Translate text using Translation API
- Display translated text
- Copy translated text
- Clear input and output
- Swap source and target languages
- Character counter
- Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- MyMemory Translation API

## 🌍 Supported Languages

- English
- Urdu
- Spanish
- French
- German
- Arabic
- Hindi
- Chinese
- Italian
- Portuguese
- Russian
- Japanese
- Korean

## 🚀 How to Use

1. Enter text in the input box.
2. Select the source language.
3. Select the target language.
4. Click the **Translate** button.
5. The translated text will appear in the output box.
6. Use **Copy** to copy the translation.
